# 수소충전소 최적 입지 선정

## 1. 프로젝트 소개

본 프로젝트는 **자가용 수소승용차의 잠재수요와 수소충전 인프라 공급 수준을 분석하여 지역별 수요·공급 불균형을 진단하고, 수소충전소 우선 확충지역을 선정**하는 것을 목적으로 한다.

전국 시군구를 대상으로 자동차 등록대수, 승용차 발생통행량, 기존 수소충전소 현황 등을 활용하여 잠재수요지수와 공급지수를 산출하고, 이를 비교하여 충전 인프라 확충이 필요한 지역을 도출하였다.

## 2. 분석 목표

- 지역별 자가용 수소승용차 잠재수요 분석
- 기존 수소충전 인프라 공급 수준 분석
- 수요·공급 불균형지수 산출
- 공급 시나리오별 민감도 분석
- 우선 확충지역 5곳 선정 및 지도 시각화

## 3. 활용 데이터

| 데이터 | 활용 목적 |
|---|---|
| 자동차 등록대수 현황 | 지역별 자가용 승용차 규모 분석 |
| KTDB 승용차 OD 통행량 | 지역별 승용차 발생통행량 분석 |
| KTDB 교통존 코드표 | 교통존과 행정구역 매핑 |
| 수소충전소 현황 | 기존 충전 인프라 공급 분석 |
| 수소충전소 충전가능차량 정보 | 승용차 충전 가능 여부 검토 |
| 수소충전소 판매량 | 충전소 이용 수준 보조 분석 |
| 행정구역 지도 데이터 | 우선 확충지역 공간 시각화 |

## 4. 분석 방법

### ① 잠재수요 분석
- 자가용 승용차 등록대수와 승용차 발생통행량을 지역별로 집계
- Min-Max 정규화를 통해 0~1 범위로 변환
- 두 지표에 동일한 가중치(각 50%)를 적용하여 잠재수요지수 산출
- 가중치 변화에 따른 민감도 분석 수행

### ② 공급 분석
- 연구용 충전소를 제외한 상업용 충전소 분석
- 기관별 충전소 데이터 매칭 및 승용차 충전 가능 여부 검토
- 지역별 충전소 수와 충전기 수를 활용하여 공급지수 산출

### ③ 수요·공급 불균형 분석
- 잠재수요지수와 공급지수를 비교하여 불균형지수 산출
- 불균형지수가 높은 지역을 우선 확충 후보지역으로 도출

### ④ 민감도 분석 및 최종 지역 선정
- 기본 시나리오: 승용차 충전 가능 후보 시설 반영
- 확대 시나리오: 승용차 충전 가능 여부 미확인 시설까지 포함
- 두 시나리오의 불균형 순위를 비교
- 보수적 순위를 활용하여 최종 우선 확충지역 5곳 선정

## 5. 주요 분석 결과

전국 228개 분석지역을 대상으로 수요·공급 불균형을 진단하였으며, 최종 우선 확충지역 5곳을 선정하였다.

| 우선순위 | 지역 |
|---|---|
| 1 | 경기도 수원시 |
| 2 | 경기도 용인시 |
| 3 | 경기도 남양주시 |
| 4 | 경기도 시흥시 |
| 5 | 경기도 고양시 |

※ 선정 결과는 분석에 사용한 데이터와 공급 시나리오를 기준으로 하며, 실제 충전소 부지의 적합성을 확정하는 결과는 아니다.

## 6. 프로젝트 폴더 구조

```text
jeonseo/
├── data/
│   ├── raw/                 # 원본 데이터
│   └── processed/

│   ├── demand/              # 잠재수요 분석 코드
│   ├── supply/              # 충전소 공급 분석 코드
│   └── integration/         # 불균형 분석 및 지역 선정 코드
│
├── results/
│   ├── demand/              # 수요 분석 결과
│   ├── supply/              # 공급 및 민감도 분석 결과
```
